# Decisions

- [[decisions/ADR-0001-outcomes-not-exceptions]] — every result is an outcome value.
- [[decisions/ADR-0002-typed-kinds]] — messages are routed by typed kind values, not runtime types.
- [[decisions/ADR-0003-pipeline-order]] — one documented order for every layer.
- [[decisions/ADR-0004-explicit-registration]] — registrations are explicit and validated at build time.
- [[decisions/ADR-0005-integrations-at-the-edge]] — other packages are used only under `Behaviors/`.
